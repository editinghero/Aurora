### Installation

1. Run `Aurora Music Player-Setup-1.0.0.exe`
2. Choose installation directory
3. Desktop and Start Menu shortcuts will be created
4. Launch Aurora Music Player

### First Use

1. Open the app
2. Click folder icon to scan music
3. Select your music folder
4. Wait for scanning to complete
5. Start playing your music

## Web App

**Location**: `dist/` folder  
**Deployment**: Ready for deployment to https://auroralocal.pages.dev

### Features

- Progressive Web App (PWA)
- Works offline after first visit
- Dynamic theme gradients
- No album artwork loading (gradient only)
- 10 color themes
- Auto-theme changes with songs
- Touch gestures support
- Responsive design
